# ქრონოლოგია

> სამუშაო ვერსია. ყველა თარიღი ჩვენი სამყაროს ალტერნატიული ისტორიაა.
>
> **მთავარი პრინციპი:** ამ სამყაროში ერებს შორის მსოფლიო ომი არ მომხდარა. „დიდი ომი“ ზედაპირისა და ქვესკნელის ომია,
> და ერები ერთად იბრძვიან. რეალური პოლიტიკური კონფლიქტები და იმპერიები ამ ისტორიაში არ მონაწილეობენ.

---

## I. მითების ხანა — ბეჭდები

- ღმერთები და გმირები თითოეული მიწის ბოროტებას ქვესკნელში კეტავენ. ყოველ მითოლოგიას თავისი ბეჭედი აქვს:
  ტიტანები ტარტაროსში, ფენრირი ჯაჭვზე, აპეპი მზის ნავის ქვეშ.
- **კოპალა** დევებს ელვით მიწის ქვეშ ერეკება. **დევების მამა** ყველაზე ღრმად, **მცირე კავკასიონის** ქვეშ იკეტება.
- ჯოჯოხეთი, ქვესკნელის ერთ-ერთი სამეფო, თავის კარიბჭეებს ხურავს და ლოდინს იწყებს. **პანდემონიუმში** ლეგიონები
  საუკუნეების განმავლობაში ემზადებიან.

## II. გმირების ხანა — ამბრი და ამირანი

- **ამირანი**, ტიტანი-გმირი, ადამიანებს რკინას აძლევს. ღმერთები მას ამისთვის კავკასიონზე აჯაჭვავენ.
- **ამბრი**, უზარმაზარი ძალის გოლიათი, ამირანს ამარცხებს. ეპოსის მიხედვით, ამბრს **ცოცხლად მარხავენ**: თორმეტი უღელი ხარი
  მას სამარხისკენ მიათრევს, ურმიდან გადმოვარდნილი ფეხი კი მიწას ხნავს.
- ამბრი არ კვდება. ის თავის ყორღანში **იძინებს** — როგორც ეპოსი ამბობს, მკვდარიც კი ძლიერია.

## III. ძველი სამეფოები — მცველები

- ორი სამეფო, **კოლხეთი** (დასავლეთი) და **იბერია** (აღმოსავლეთი), მცირე კავკასიონის ბეჭდის მცველები ხდებიან.
- კოლხეთი ინახავს **ოქროს საწმისს** და მის მცველ, არასოდეს მძინარე **დრაკონს**.
- ხვამლის მთის გამოქვაბულებში მეფეები თავიანთ **საგანძურს** მალავენ.
- ორივე სამეფო საუკუნეების განმავლობაში ძველ ფიცს ინახავს — მიწის ქვეშ არაფერი უნდა გამოუშვან.
  დროთა განმავლობაში ხალხს ფიცის მიზეზი ავიწყდება და ის ჩვეულებად იქცევა.

## IV. ორთქლის საუკუნე (1850–1890)

| წელი | მოვლენა |
|---|---|
| **1850-იანები** | ორთქლის ძრავები კოლხეთსა და იბერიაში ვრცელდება. იწყება მჭედლობის და ქარხნების ხანა. |
| **1872** | **კოლხეთ-იბერიის რკინიგზა** — პირველი ხაზი მთებს კვეთს ზღვიდან აღმოსავლეთამდე. |
| **1879** | იხსნება **შავი შახტი** — ყველაზე ღრმა მაღარო მცირე კავკასიონის ძირას. |
| **1880-იანები** | მთელ მსოფლიოში მაღაროები და გვირაბები უფრო ღრმად ჩადის, ვიდრე ოდესმე. არქეოლოგები ძველ ყორღანებს ხსნიან. |

## V. ბზარის წლები (1888–1899)

| წელი | მოვლენა |
|---|---|
| **1888** | **შავ შახტში** მაღაროელები ქრებიან. ზოგი ბრუნდება — სხვანაირი. ისინი ამბობენ, რომ ქვემოთ ვიღაც ელაპარაკებოდათ. |
| **1891** | **პირველი კარიბჭეები.** მსოფლიოს სხვადასხვა კუთხეში — მინდვრებში, მაღაროებში, ტბების ფსკერზე — პატარა ნაპრალები იხსნება. ყოველი მიწიდან მისივე მითოლოგიის ბოროტება ამოდის. |
| **1893** | **ჯოჯოხეთის ლეგიონები** პირველად ჩნდებიან — წოდებებით, დროშებით და ბრძანებებით. ცხადი ხდება, რომ ეს დაგეგმილი ომია. |
| **1896** | **ამბოხის წელი.** ბევრ ქვეყანაში ერთდროულად იწყება აჯანყებები. ერეტიკოსები პირველად იბრძვიან საკუთარი ხალხის წინააღმდეგ. |
| **1898** | **კოალიციის ფიცი.** ერები, რომლებსაც მანამდე საერთო არაფერი ჰქონდათ, ერთად დგებიან ქვესკნელის წინააღმდეგ. |
| **1899** | **ღმერთების ბოლო საჩუქარი.** კეთილი ღმერთები ადამიანებს მჭედლობის ცოდნას აძლევენ — შავხანის, ჰეფესტოს, სვაროგის და სხვა მჭედელი ღმერთების ცოდნით პირველი **გოლიათები** და ალქიმიის საიდუმლოებები ჩნდება. |

## VI. დიდი გარღვევა (1902–1903)

| წელი | მოვლენა |
|---|---|
| **1902, გაზაფხული** | **მცირე კავკასიონის კარიბჭე** იხსნება — ყველაზე დიდი ყველა კარიბჭეს შორის. ამოდის **დევების მამა** და მის უკან ჯოჯოხეთის ლეგიონები. |
| **1902, ზაფხული** | კოლხეთი და იბერია უკან იხევენ. ფრონტი თითქმის ირღვევა. |
| **1902, შემოდგომა** | იბერიის მჭედლები **ამირანს ათავისუფლებენ** ძველი ჯაჭვებიდან, რომ დევების მამას შეებრძოლოს. ამირანი რკინის ჯავშანში გამოდის ბრძოლაში, მაგრამ დევების მამის თავები ხელახლა იზრდება — მისი მოკვლა შეუძლებელია. |
| **1902, ზამთარი** | **ამირანის ჯაჭვები** ხვამლზე მიაქვთ. ირკვევა, რომ ეს ჯაჭვები ერთადერთია, რასაც შეუძლია ქვესკნელის ბეჭდის გახსნაც და დახურვაც. **კეთილი ღმერთები** ხვამლზე ჯაჭვების დასაცავად იფიცებიან — და ამ ფიცით მიბმულნი, ფრონტს ვეღარ ეხმარებიან. |
| **1903** | კოლხები **ამბრის ძველ ყორღანს** თხრიან და მძინარე გოლიათს აღვიძებენ. |
| **1903, „ამბრის დაკრძალვის დღე“** | **თორმეტი უღელი ორთქლის ხარი** — ისევე როგორც ეპოსში — ცოცხალ ამბრს კარიბჭემდე მიათრევს. მისი ფეხი მიწას ხნავს და ტოვებს ღარს, რომელიც **მთავარი სანგარი** ხდება. ამბრი ნებით წვება კარიბჭეში და თავისი სხეულით ხშობს მას. დევების მამა ქვემოთ რჩება. |
| **1903** | კარიბჭის ადგილას რჩება კრატერი — **ჭრილობა**. ამბრის სხეული ბეჭდის **საკეტია**, ხვამლის ჯაჭვები — **გასაღები**. |

## VII. სანგრების ომი (1904–1913)

| წელი | მოვლენა |
|---|---|
| **1904–1906** | ჭრილობის გარშემო **სანგრების რგოლი** ყალიბდება. ჩრდილოეთით კოლხეთი და იბერია, სამხრეთით და აღმოსავლეთით მეზობელი ერების ჯარები. |
| **1907** | ერეტიკოსები იგებენ, რომ ბეჭდის გასატეხად ორი რამ სჭირდებათ: **ხვამლის ჯაჭვები** და **სისხლი ამბრის საფლავზე**. |
| **1908** | **ერეტიკოსების პირველი ლაშქრობა ხვამლზე.** რაზმიდან უკან არავინ ბრუნდება. ამის შემდეგ ხვამლზე ლაშქრობას აღარავინ ბედავს. |
| **1909** | ჭრილობის შიგნით იწყება **დიდი უღლის** მშენებლობა. არქიტექტორია **მულციბერი**, ინჟინრები — დაცემული **„მცველები“**, აზაზელი და გადრეელი. მუშახელი — ერეტიკოსები და ტყვეები. |
| **1911** | **დიდი უღლის პირველი მარში.** უღელში შებმული დევები და ტყვე გოლიათები ქალაქს პირველად ამოძრავებენ. ომის ყველაზე სისხლიანი წელი. |
| **1912** | ნათელი მხარე პირველად აჩერებს დიდ უღელს — **საწმისის დრაკონი** და **ამირანი** ერთად ებრძვიან **ბაყბაყ-დევს**. დიდი უღელი უკან იხევს. |
| **1913** | ფრონტზე ჩამოდის **ბელზებელი** — ჯოჯოხეთის ფრონტის გენერალი — და თავის შტაბს დიდ უღელზე აწყობს. ლეგიონები უფრო მოწესრიგებულად და უფრო დაგეგმილად იწყებენ ბრძოლას. |

## VIII. 1914 — აწმყო (თამაშის დასაწყისი)

- დიდი უღელი ახალი მარშრუტით **ამბრის საფლავისკენ** ბრუნდება.
- სამსხვერპლოზე ტყვეები ყოველდღე იწირებიან. ერეტიკოსებს მეტი ტყვე სჭირდებათ, ამიტომ ნეიტრალურ ზოლში თავდასხმები ხშირდება.
- ფრონტი იქ მოძრაობს, სადაც დიდი უღელი მიდის.
- ნეიტრალურ ზოლში მცირე რაზმები იბრძვიან — **აქედან იწყება თამაში.**

---

## ღია საკითხები
- მეზობელი ერების ფრონტების ქრონოლოგია.
- სხვა კარიბჭეები მსოფლიოში (საბერძნეთი, ჩრდილოეთი, ეგვიპტე და ა.შ.) — როდის და როგორ გაიღო.
- სახელდებული ბრძოლები 1904–1913 წლებში.
