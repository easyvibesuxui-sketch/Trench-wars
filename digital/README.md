# სოფლის ფრონტი — ციფრული პროტოტიპი

რეალურ დროში სტრატეგიის (AoE/AoM) პირველი სათამაშო ნაჭერი ბრაუზერში: **კოლხეთი** (მოთამაშე) **დიდი უღლის** (კომპიუტერი) წინააღმდეგ.
გახსენი `index.html` ბრაუზერში (მონაცემები — `data.js`, რომელსაც `tools/build_builder.py` აწყობს).

**რა არის:** სოფელი-ბაზა (შტაბი, სოფლის სახლები, მინდორი, ტყე, მაღარო, კარიერი) · მზიდავები (რესურსს ზიდავენ, არ არიან სამიზნე) ·
4 რესურსი (საკვები, ქვანახშირი/შეშა, ქვა, რკინა) და მოსახლეობის ლიმიტი · 2 ეპოქა (ბეჭდების → ორთქლის) · შენობები: ბლინდაჟი, ყაზარმა,
ხის მესერი → ქვის კედელი, თხრილი, საგუშაგო კოშკი, ტყვიამფრქვევის ბუდე, ორთქლის სახელოსნო · იუნიტები `data/units.json`-დან, სამაგიდო
d10 წესებით (მოხვედრა, დაჭრა, საფარი, ცეცხლი, ამოზრდა) · **დათრგუნვა** (ტყვიამფრქვევი ქვეითს აწვენს) · ნეიტრალური ზოლი ამბრის ღარით
და ნანგრევებით (საფარი) · კომპიუტერის ეკონომიკა, ჯარი და ტალღები.

**ფრაქციების არქიტექტურა:** კოლხეთი — ბოძებზე დგმული სახლები და სვანური კოშკი; დიდი უღელი — ურმები ბორბლებით და ჯაჭვით შეკრული ურმების წრე.

**მართვა:** მონიშვნა — დაჭერა ან ჩარჩო; სვლა — ველზე დაჭერა (ან მარჯვენა ღილაკი); შენება — ღილაკი, მერე ადგილი სოფელში; R — კედლის
მობრუნება; Esc — გაუქმება. ღილაკი „შეტევა ღარის გავლით“ — მთელი ჯარი მოწინააღმდეგის შტაბზე.

**შემდეგი ნაბიჯები:** ყველა ფრაქცია, III–IV ეპოქა და გოლიათი, ფრაქციის უნიკალური თავდაცვა (`docs/architecture.md`, ნაწილი 8),
ნეიტრალური ზოლის ზონები და ურჩხულები, ალიანსები და დიპლომატია, მულტიპლეერი.
