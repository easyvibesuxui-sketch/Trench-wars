# ვიზუალური მიმართულება — იუნიტები და ფრაქციები

> მხატვრებისთვის, მინიატურების სკულპტორებისთვის და ციფრული თამაშისთვის. ფერადი ვერსია — `playtest/visual-guide.html`.

## საერთო პრინციპები

- **სტილი:** 1914 წლის ლითოგრაფიული პლაკატი + ხის/ლინოს გრავიურა + ძველი სატირული ომის რუკები: სქელი კონტური, 3–4 ბრტყელი ფერი, ქაღალდის მარცვალი. ფონი — ჩამქრალი მიწისფერები, ფრაქციას — ერთი მკვეთრი აქცენტი.
- **Trench Crusade-ისგან განსხვავება:** Trench Crusade-ისგან განსხვავება: არა ზეთის მხატვრობა, ვიტრაჟი, შარავანდედი, წმინდანები, გოთიკური ტაძრის ფორმები და დეტალური სხეულის საშინელება (body horror) — ჩვენი ტონი მითოლოგიური ხალხური ხელოვნებაა (ბრინჯაოს ორნამენტი, ხალხური ქსოვილი, კოშკები), საშინელება — ნაგულისხმევი.
- **სილუეტი:** მინიატურის (28–32 მმ) ზომაზე ფრაქცია სილუეტით უნდა იცნობოდეს: თავსაბურავი, ფარი და ზურგის აღჭურვილობა — ფრაქციის სამი „ნიშანი“.
- **სისასტიკე:** სისხლი და ჭრილობა — ნაგულისხმევი (ბნელი ლაქა, შეხვეული ჭრილობა), არა დეტალური.
- **კონსულტანტები:** მოკავშირე ფრაქციების ილუსტრაციამდე — ამ კულტურის კონსულტანტის შემოწმება (განსაკუთრებით ამერიკის, ოკეანეთის, ავსტრალიისა და არქტიკის ხალხებზე).

**დონეები ვიზუალურად:**

- **I** — ჩვეულებრივი ადამიანის ზომა, უბრალო ფორმა, ცოტა დეტალი
- **II** — გამორჩეული თავსაბურავი ან მოსასხამი, ფრაქციის ემბლემა მკერდზე
- **III** — ჯავშანი ან პროთეზები, ~1,2-ჯერ მასიური სილუეტი
- **IV** — მანქანა ან არსება, 2–3-ჯერ მაღალი, ფრაქციის ფორმა მთელ სხეულზე
- **IV+** — მავალი ნაგებობა — ციხე, ურემი, მატარებელი
- **V** — გოლიათი: სახლებზე მაღალი, ფრაქციის მითის ცენტრალური ფიგურა
- **hero** — სახელიანი პერსონაჟი: უნიკალური სახე და ერთი დასამახსოვრებელი ნივთი

**არასოდეს:**

- რეალური რელიგიური სიმბოლოები: ჯვარი, ნახევარმთვარე, დავითის ვარსკვლავი, შარავანდედი, წმინდანები, ტაძრები, ვიტრაჟი
- გრიმუარების რეალური ბეჭდები (სიგილები) — ჯოჯოხეთის ნიშნები ჩვენი დახატულია
- ნაცისტების მიერ მითვისებული სიმბოლოები: რუნები (ზიგ, ოდალი...), თავის ქალა-ძვლები (Totenkopf), შავი მზე
- რეალური სახელმწიფო გერბები და დროშები ბნელ მხარეს; ეთნიკური კარიკატურა; რეალური სისასტიკის გამოსახულება
- წმინდა სამოსი და სიმბოლოები ცოცხალი ტრადიციებიდან: ბუმბულის საომარი გვირგვინი, მაორის ტა-მოკო, აბორიგენული წერტილოვანი მხატვრობა და სხვ.
- მშვიდობიანი მოსახლეობა მსხვერპლად; წამების დეტალები
- წითელი ჯვარი / ნახევარმთვარე (დაცული ემბლემა) — მკურნალებს უბრალო სამკლავური; აწეული ხელის მისალმება
- რეალური დიქტატორების და ისტორიული ლიდერების მსგავსება (მაგ. სქელი ულვაში + კეპი + ხაკის კიტელი = სტალინის სილუეტი)
- პოლიტიკურად დატვირთული ფორმის ფერები: ნაცრისფერი კიტელი + სამკლავური (ფაშიზმი), ზეთისხილისფერი-ხაკი კიტელი + კეპი (საბჭოთა არმია), შავი ფორმა + წითელი სამკლავური

## TC-სთან მგრძნობიარე იუნიტები

> შედარება ოფიციალურ „Warbands of Trench Crusade“-თან (2026 წლის სექტემბრის ვერსია).

- **ხალკოტავრი** — TC-ს ჰყავს „ბრინჯაოს ხარი“ (Brazen Bull) — რკინის სულთანატის ცოცხალი ალყის მანქანა ცეცხლის ზარბაზნით. ჩვენი ხალკოტავრი ოქროს საწმისის მითიდანაა: ოთხფეხა ხარი პირიდან ცეცხლით, კოლხური გეომეტრიული ორნამენტით, მწყემსი წინ ურტყამს ხელკეტს. არანაირი ზარბაზანი ზურგზე, არანაირი აღმოსავლური/ოსმალური სტილი, მწვანე პატინა.
- **იანიჩრები** — TC-ში „იანიჩრები“ რკინის სულთანატის ქვეითია (55 დუკატი). ჩვენები ქალაქის საამქროების მოხალისე-ჯარისკაცები არიან: ბაზრის ქსოვილი, ტუმბოს შლანგი, ხანძრის მქრობელის ჩაფხუტი — არა სულთნის გვარდია, არა თეთრი ბორკი.
- **სიფაჰები** — TC-ს ჰყავს „სიფაჰის ავტომატი-ცხენოსანი“ (ვარიანტი). ჩვენი სიფაჰები ცოცხალი მხედრები არიან ცოცხალ ცხენებზე, ავტომატების გარეშე.
- **მაგნაურას ორთქლის ლომი** — TC-ში „ჯაბირის ლომები“ ალქიმიური არსებებია. ჩვენი მაგნაურას ლომი ისტორიული ტახტის ავტომატის (X ს., ლიუდპრანდი) ორთქლის ვერსიაა: ოქროს ფირფიტა, მექანიკური ღრიალი, ცერემონიული ფორმა.
- **უღლის მონები** — TC-ს ჰყავს „უღლის ფენდები“ (Yoke Fiends). ინგლისურ ვერსიაში სახელი შევცვალოთ (მაგ. Harness-bound), ვიზუალი: ჯაჭვით შეკრული ადამიანთა ჯგუფი ერთ ძელზე, არა დემონი.
- **ავტომატ-ფალანგა** — ავტომატები TC-შიც არის (სიფაჰი). ჩვენი ფალანგა ბერძნული ბრინჯაოს ტალოსის მოტივია — ფარების კედელი, არა ცხენოსანი.
