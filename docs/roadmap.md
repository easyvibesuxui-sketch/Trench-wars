# ქვესკნელის ფრონტი — პროდუქტები და სამოქმედო გეგმა

სამუშაო დოკუმენტი (2026 წლის ნოემბერი). ბრენდი: **ქვესკნელის ფრონტი / Underfront** — ერთი სამყარო, ერთი მონაცემთა ბაზა (`data/`),
რამდენიმე თამაში. ვადები ფარდობითია (კვირები გეგმის დაწყებიდან) და დამოკიდებულია გუნდზე და ბიუჯეტზე (იხ. „გადასაწყვეტი საკითხები“).

**რეკომენდაცია — პრიორიტეტი:**
1. **სანგრის რიგი** — ყველაზე სწრაფად გასაყვანი (ბრაუზერი/ტელეფონი, ერთი მოთამაშე, სერვერის გარეშე), სამყაროს „კარიბჭე“.
2. **სამაგიდო სკირმიში** — მთავარი IP; ტესტები ახლავე, ბეჭდვა და მინიატიურები — მოგვიანებით, crowdfunding-ით.
3. **სამი ხაზი** — თითქმის მზადაა; იაფი ბეჭდვა (print-on-demand) მარკეტინგისთვის და ტესტებისთვის.
4. **ბოლო ზღუდე** — შენარჩუნება, სხვა პროდუქტების ბონუს-რეჟიმი.
5. **RTS** — გაყინული, სანამ 1–2 პროდუქტი არ გამოვა და გუნდი/ბიუჯეტი არ გაჩნდება.

## 2. სამოქმედო გეგმა

### ფაზა 0 — საფუძველი (კვირა 1–2)
- [ ] საბოლოო სახელი: „ქვესკნელის ფრონტი / Underfront“ — სასაქონლო ნიშნის და დომენის შემოწმება (საქართველო, EU, US).
- [ ] რეპოს სახელის შეცვლა (`Trench-wars` → `underfront`), README-ის განახლება.
- [ ] იურიდიული: ორიგინალობის აუდიტი (`docs/fact-check.md`) იურისტთან; Kling-ის სურათების კომერციული ლიცენზიის დადასტურება.
- [ ] ჰოსტინგი: სანგრის რიგი, ვიკი და ბილდერი ერთ საიტზე (მაგ. Vercel ან Netlify), საკუთარ დომენზე.
- [ ] ანალიტიკა (ანონიმური): გარბენის სიგრძე, მოგების %, სად წყვეტენ თამაშს.

### ფაზა 1 — სანგრის რიგი: ტესტი და გაპრიალება (კვირა 2–6)
- [ ] **10–20 მოთამაშის ტესტი** (მეგობრები, ქართული სათამაშო თემები): 3 გარბენი თითოეულზე, მოკლე კითხვარი.
- [ ] **სწავლება:** პირველი გარბენი — ნაბიჯ-ნაბიჯ (აყვანა → განლაგება → ბრძოლა → სამეული → დონე).
- [ ] **გრაფიკა (Kling):** ბარათის ჩარჩოები ფრაქციების მიხედვით, მარაგის ბარათების ილუსტრაციები, ველის ფონები, რუკა, ხატულები.
- [ ] **ხმა:** მუსიკა (2–3 თემა), ბრძოლის ხმები ნიმუშებით (ახლა სინთეზირებულია).
- [ ] **PWA:** ინსტალაცია ტელეფონზე, ოფლაინ თამაში.
- [ ] ბალანსი ადამიანების შედეგებით (ბოტის 48–61%-ის გადამოწმება); სიმძიმის საფეხურების გადახედვა.
- **შედეგი:** სანგრის რიგი 1.0 ვებში. **საზომი:** მეორე დღის დაბრუნება ≥ 30%, საშუალო სესია ≥ 15 წთ.

### ფაზა 2 — სანგრის რიგი: შინაარსი და გამოშვება (კვირა 6–12)
- [ ] ფრაქციების უნიკალური უნარები (თითოს 1 მექანიკა), მეტი რელიქვია და ხდომილება, სეზონური წესები.
- [ ] **ასინქრონული PvP:** მოთამაშეების ჯარები ინახება და სხვები მათ „მოჩვენებად“ ხვდებიან (საჭიროა სერვერი, მაგ. Supabase).
- [ ] ლიდერბორდი, დღის გამოწვევის რეიტინგი.
- [ ] ტელეფონის აპები (Capacitor ან მსგავსი) → Google Play, შემდეგ App Store.
- [ ] ინგლისური ვერსიის რედაქტურა; შემდეგი ენები — მოთხოვნის მიხედვით.
- **შედეგი:** მაღაზიებში გამოშვება. **ბიზნეს-მოდელი:** გადასაწყვეტია (იხ. ქვემოთ).

### ფაზა 3 — სამაგიდო თამაში (პარალელურად, კვირა 2–16)
- [ ] **ტესტ-სესიები:** 5–10 თამაში დასაბეჭდი ნაკრებით (`playtest/kit.pdf`, `warbands.pdf`), ჩანაწერები → წესების შესწორება.
- [ ] წესების წიგნის დიზაინი და აწყობა (ბრენდის სტილით), ინგლისური თარგმანის რედაქტურა.
- [ ] **მინიატიურები:** კონცეპტ-არტი ძირითადი 7 ფრაქციისთვის (Kling, `docs/visual-guide.md`), შემდეგ 3D მოდელერი → STL (ციფრული გაყიდვა) ან ჩამოსხმა.
- [ ] **სამი ხაზი:** ბარათების საბოლოო განლაგება და print-on-demand ტირაჟი (სატესტო და საპრომო).
- [ ] crowdfunding-ის მომზადება: გვერდი, ვიდეო, ჯილდოების დონეები, სათემო ბაზა (Discord, სოციალური ქსელები).
- **შედეგი:** crowdfunding-ის კამპანია ~16-ე კვირიდან (თუ გადავწყვეტთ).

### ფაზა 4 — ბოლო ზღუდე და RTS (კვირა 12+)
- [ ] ბოლო ზღუდე: ტელეფონის ეკრანი, 40/59 ტალღის ბალანსი, სანგრის რიგის ბარათებთან კავშირი (ბონუს-რეჟიმი).
- [ ] RTS: ძრავის არჩევა (Godot / ვები), 2 ფრაქციის „vertical slice“, გუნდის და ბიუჯეტის გეგმა — მხოლოდ 1–2 პროდუქტის გამოშვების შემდეგ.

### მუდმივად
- ლორის და ვიკის განახლება ყოველ ახალ შინაარსზე; ორიგინალობის და პოლიტკორექტულობის წესები (`README.md`, `docs/fact-check.md`).
- ბალანსის ინსტრუმენტები (`tools/balancer.py`, `tools/tune_factions.js`) ყოველი ცვლილების შემდეგ.
- თემთან კომუნიკაცია: დევბლოგი, ტესტერების ჯგუფი.

## 3. გადასაწყვეტი საკითხები
1. **პრიორიტეტი:** ეთანხმები თანმიმდევრობას — სანგრის რიგი → სამაგიდო → სამი ხაზი → ბოლო ზღუდე → RTS?
2. **ბიზნეს-მოდელი სანგრის რიგისთვის:** ა) უფასო + კოსმეტიკა (ბარათის ჩარჩოები, ვარიანტები); ბ) ფასიანი (ერთჯერადი ყიდვა); გ) უფასო ვებ-ვერსია + ფასიანი აპი; დ) ჯერ უფასო, მოდელი — მოგვიანებით.
3. **გუნდი და ბიუჯეტი:** ვინ მუშაობს (შენ, მე, მხატვარი, კომპოზიტორი, 3D მოდელერი)? ბიუჯეტი Kling-ისთვის, ხმისთვის, მინიატიურებისთვის, იურისტისთვის?
4. **ბაზარი და ენა:** ჯერ საქართველო (ქართული) თუ ერთდროულად საერთაშორისო (ინგლისური)?
5. **სამაგიდო:** მინიატიურები (ჩამოსხმა) თუ ციფრული STL, თუ მხოლოდ ბარათები და წესები?
6. **ვადა:** არის თუ არა სასურველი გამოშვების თარიღი (მაგ. ფესტივალი, გამოფენა)?

## 4. უახლოესი ორი კვირა
1. გადასაწყვეტ საკითხებზე პასუხი (ზემოთ).
2. სახელის და ნიშნის შემოწმება; რეპოს სახელის შეცვლა.
3. სანგრის რიგის საიტზე გამოქვეყნება და პირველი 10 ტესტერის მოწვევა; კითხვარი.
4. სწავლების (tutorial) პირველი ვერსია.
5. სამაგიდო თამაშის პირველი 2 ტესტ-სესია ნაკრებით.
