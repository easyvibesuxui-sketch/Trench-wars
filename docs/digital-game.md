# ციფრული თამაში (პროდუქტი B) — ჰიბრიდული დიზაინი

> სამუშაო ვერსია. **არჩეულია ვარიანტი 2 — ჰიბრიდი:** სანგრების ფრონტი, ბაზის მშენებლობის გარეშე, და მასზე
> Age of Mythology-ს ტიპის ღმერთების სისტემა (ღმერთის არჩევა, ეპოქები, ღვთაებრივი ძალები).
> ლორი და იუნიტები საერთოა სამაგიდო თამაშთან (`data/units.json`).

---

## 2. ბრძოლის ველი
- **ფრონტი, არა ბაზა:** რუკა სანგრების ზოლებადაა დაყოფილი. მოთამაშე სანგრებს იკავებს, თხრის და ამაგრებს. ბაზის მშენებლობა არ არის.
- **ეკონომიკა:** მარაგი მოდის ზურგის ხაზებიდან (მარაგის წერტილები რუკაზე). ყველა აღებული სანგარი შემოსავალს ზრდის.
- **ჯარი:** იუნიტები სამაგიდო თამაშის დონეებიდან (I–IV); **V დონის გოლიათი** — ერთი, ბოლო ეპოქაში.
- **დიდი უღელი:** ბნელი მხარის ზოგ რუკაზე ქალაქი ნელა მოძრაობს. ნათელმა მხარემ ის საფლავამდე არ უნდა მიუშვას.

## 3. ღმერთების სისტემა

### უზენაესი ღმერთი (თამაშის დასაწყისში)
- **ნათელი:** ყოველ ფრაქციას თავისი უზენაესი ღმერთი ჰყავს (კოლხეთი/იბერია — **არმაზი**; ელინები — ზევსი; ოღუზები — თენგრი...).
  ზოგ ფრაქციას შეიძლება 2–3 ვარიანტი ჰქონდეს: მაგ. იბერია — არმაზი, ან **კოპალა** (ელვის გზა), ან **დალი** (მონადირის გზა).
- **ბნელი:** ჯოჯოხეთის ლეგიონები ირჩევენ **გენერალს** (ბაალი, ბელზებელი, ასმოდეუსი...); დიდი უღელი — **ბელადს** (უსახელო, ბაყბაყ-დევი...).

### ეპოქები (4) და მცირე მფარველები
| ეპოქა | სახელი (სამუშაო) | რა იხსნება |
|---|---|---|
| I | **ბეჭდების ეპოქა** | ქვეითი, თხრილები |
| II | **ორთქლის ეპოქა** | ელიტა, პირველი მცირე მფარველი |
| III | **ფოლადის ეპოქა** | ჯავშნიანები, გროტესკულები, მეორე მფარველი |
| IV | **გოლიათების ეპოქა** | V დონის გოლიათი, მესამე მფარველი |

ყოველ ეპოქაზე ორი მცირე მფარველიდან ერთს ირჩევ; არჩევანი შეუქცევადია. მაგალითი — **იბერია (არმაზი):**
- II: **იახსარი** (ფარისნები ძლიერდებიან) ან **პირქუშა** (მეხის იარაღი იაფდება)
- III: **კოპალა** (ელვა დევებზე) ან **დალი** (მონადირეები, ჯიხვი)
- IV: **გაცი** (ოქრო — ალქიმია) ან **გაიმი** (ვერცხლი — დაცვა წყევლისგან)

### ღვთაებრივი რესურსი — თითო ფრაქციას თავისი გზა
| ფრაქცია | რესურსი | როგორ გროვდება |
|---|---|---|
| კოლხეთი, იბერია, მოკავშირეები | **სახელი** | ფიცით და ღვაწლით: მტრის ლიდერის მოკვლა, სანგრის შენარჩუნება, ტყვის გამოხსნა |
| ჯოჯოხეთის ლეგიონები | **წოდება** | წესრიგით: წყობაში დგომა, ბრძანებების შესრულება |
| დიდი უღელი | **სისხლი** | ტყვეებით და მსხვერპლით (საკუთარი მეომრებისაც) |

### ღვთაებრივი ძალები — „ნიშნები“
ლორში ღმერთები ფრონტზე **ვერ ჩამოდიან** — ისინი ზეციურ ომში არიან. ამიტომ მათი ძალა ზემოდან ნიშნად მოდის:
- **არმაზის ზღვა** — ტალღა, რომელიც სანგარს რეცხავს (ძველი ტექსტი: არმაზი ზღვას იარაღად იყენებს).
- **კოპალას მეხი** — ელვა უღრუბლო ცაზე: ერთი დევი ან გროტესკი იწვის.
- **ცოცხალი წყლის წყარო** — ერთ ადგილას დაცემულები დგებიან.
- **ბნელი:** ბაალის **ბრძანება** (მთელი ლეგიონი ერთ ზალპს ისვრის), უღლის **სისხლის წვიმა**.
ძალა ერთჯერადია ან დიდი გადატვირთვით — ბალანსი ტესტირებით.

### სამკუთხედი
**ქვეითი** → სძლევს გმირებს/ელიტას (რაოდენობით) · **ელიტა და მონადირეები** → სძლევენ ურჩხულებს და გოლიათებს ·
**ურჩხულები და გროტესკები** → სძლევენ ქვეითს. ეს უკვე ჩაშენებულია სამაგიდო იუნიტებში (`giant_hunter`, `monster_hunter`).

## 4. კამპანიები
სტრუქტურა — იხ. `../lore/09-separate-wars.md`:
- **მთავარი კამპანია — ჭრილობის ომი:** 12 სახელდებული ბრძოლა (`../lore/03-named-battles.md`), 1847–1913.
- **ომის კამპანიები:** 41 კამპანია (ყოველ ფრაქციას — 5 სცენარი), თავისი გმირით, მტრით და **მსხვერპლით** — გამოგონილი ადამიანით, რომელმაც დიდი ურჩხულის შემოტევა შეაჩერა; მისი ადგილი ერთ სცენარად თამაშდება. წყარო: `../data/campaigns/`, ტექსტი: `../campaigns/`.
- **ფინალი 1914:** საკეტები შეგროვდა — დიდი უღელი ამბრის საფლავისკენ.

## 5. ცალკე მატჩები (კამპანიის გარდა)

Age of Mythology-ის მსგავსად, კამპანიის გარდა თამაშს აქვს **ცალკე მატჩები** — კომპიუტერის ან ადამიანების წინააღმდეგ.
ეს მატჩები ლორის „კანონი“ არ არის: ისინი „ფრონტის ლეგენდებია“ — ბრძოლები, რომლებიც შეიძლება მომხდარიყო.

### მოთამაშეები და გუნდები
| ფორმატი | აღწერა |
|---|---|
| **1 vs 1** | კლასიკური დუელი |
| **2 vs 2, 3 vs 3, 4 vs 4** | გუნდური მატჩები; გუნდის წევრები მარაგს და ხედვას იზიარებენ |
| **ყველა ყველას წინააღმდეგ** (3–8) | თითოეული თავისთვის |
| **ერთად კომპიუტერის წინააღმდეგ** (1–4 მოთამაშე) | თანამშრომლობა AI-ის ჯარის წინააღმდეგ |
| **მატჩი კომპიუტერთან** | 1 მოთამაშე და 1–7 AI, სირთულე: ახალწვეული · ვეტერანი · ჯოჯოხეთის მარკიზი · დიდი უღელი |

- **ფრაქცია:** ყველა ფრაქცია ხელმისაწვდომია — 4 ძირითადი და ყველა მოკავშირე. ნებისმიერ ფრაქციას ნებისმიერის წინააღმდეგ შეუძლია ბრძოლა.
- **„ლორის წესი“ (ოფცია):** მხოლოდ ნათელი vs ბნელი; ნათელ გუნდში მოკავშირეები და კოლხეთი/იბერია ერთად.
- **უზენაესი ღმერთის/გენერლის არჩევა** მატჩის დასაწყისში — როგორც AoM-ში მთავარი ღმერთის არჩევა (იხ. ნაწილი 3).

### მატჩის რეჟიმები
| რეჟიმი | მიზანი |
|---|---|
| **ფრონტის გარღვევა** | მოწინააღმდეგის შტაბის და ყველა სანგრის ხაზის აღება — სტანდარტული რეჟიმი |
| **ჭრილობის მწვერვალი** | რუკის ცენტრში მდგარი ბეჭდის (ამბრის საფლავის) ფლობა განსაზღვრული დროით |
| **ბეჭდის ნამსხვრევები** | რუკაზე მიმოფანტული ბეჭდის ნამსხვრევების შეგროვება — თითოეული ღვთაებრივ რესურსს აძლევს; ყველას ფლობა = გამარჯვება |
| **დიდი უღლის მარში** | ასიმეტრიული: ერთი გუნდი მავალ ქალაქს რუკის ბოლომდე მიაცილებს, მეორე აჩერებს |
| **ზავი** | პირველი N წუთი თავდასხმა აკრძალულია — მხოლოდ სანგრები და ეკონომიკა |
| **ბელადზე ნადირობა** | ყველა მოთამაშეს ჰყავს ბელადი; ვინც ბელადს კარგავს, მარცხდება |
| **გოლიათების ომი** | მატჩი გოლიათების ეპოქიდან იწყება, დიდი რესურსით |
| **სწრაფი ბრძოლა** | პატარა რუკა, სწრაფი ეპოქები, მოკლე მატჩი |

### რუკები
- **ფრონტის რუკები:** ჭრილობის რგოლი, ამბრის ღარი, ზღვის კარი, დრაკონის ველი, ძვლების ტყე, მავთულის ზამთარი.
- **ცალკე ომების რუკები:** თითო ომზე ერთი — ბერძნული კუნძულები ქარიშხლით, ჩრდილოეთის ფიორდები, ნილოსის ღამის უდაბნო, ამაზონის წყლების
  შეხვედრა, ანდების ხიდები, ცისფერი ორმოები, გობის რკინის ხაზები და სხვ. (იხ. `../lore/09-separate-wars.md`).
- **შემთხვევითი რუკა:** გენერატორი ბიომით (მთა, ტყე, უდაბნო, ზღვისპირა, კუნძულები, ზამთარი), სანგრების სიხშირით და კარიბჭეების რაოდენობით.
- **რუკის მოვლენები (ოფცია):** გაზის ღრუბელი ქარით, მზის დაბნელება, მტვრის ქარიშხალი, ღამე — რუკის მიხედვით.

### რეიტინგი და სოციალური
- რეიტინგული (1v1, 2v2, 3v3, 4v4) და თავისუფალი მატჩები; ჩანაწერები და მატჩის განმეორება.
- ⚠️ რეიტინგულ რეჟიმში ბალანსი ბალანსერის ციფრული ვერსიით უნდა შემოწმდეს (იხ. `../tools/balancer.py` — ციფრული თამაშის ადაპტაცია მოგვიანებით).

## 6. ტექნიკური შენიშვნები (ადრეული)
- ძრავა: Godot (2D/იზომეტრია) ან ვებზე Phaser — პროტოტიპისთვის ვებ-ვერსია უფრო სწრაფია.
- მონაცემები: `data/units.json`-დან; ციფრულ თამაშს დაემატება `hp`/`dps`-ის კონვერტაცია d10 მაჩვენებლებიდან.
- თანმიმდევრობა: 1) ერთი რუკა, ორი ფრაქცია, ეპოქები ღმერთების გარეშე, 1v1 → 2) ღმერთების სისტემა → 3) გოლიათები → 4) გუნდური და AI მატჩები →
  5) კამპანია.
