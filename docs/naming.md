# სახელების სახელმძღვანელო

> Warhammer-ის სახელების **ხერხებს** ვიყენებთ, მაგრამ არა მის სახელებსა და სიტყვებს. იხ. `fact-check.md` და
> ლორის წესები — `../lore/`.

## რას აკეთებს Warhammer და რა არის ჩვენი ვერსია

| Warhammer-ის ხერხი | მაგალითი (მხოლოდ ასახსნელად) | ჩვენი ვერსია |
|---|---|---|
| **მაღალი სტილის ენა** ინსტიტუტებისა და ტიტულებისთვის | ლათინური: Adeptus, Officio, Imperium | **ძველი ქართული სახელმწიფო ენა**: -თუხუცესი, -მთავარი, სპა-, ერის-, მანდატური, ამილახორი. მაგ. **უღლისმთავარი**, ბეჭდისთუხუცესი |
| **სახელი-აღწერა** | Ferrus Manus („რკინის ხელი“), Corax („ყორანი“) | **ქართული მეტსახელი**: ბრინჯაოსმკლავა, მეხისთვალა, ოთხენოვანი, ცალხელა |
| **მითის ან ისტორიის საყრდენი** | Horus, Erebus, მონღოლები, ვიკინგები | ქართული მითი (ამბრი, ამირანი, ქაჯები, დევები), გრიმუარები ლეგიონებისთვის, ყოველი მოკავშირის საკუთარი ეპოსი |
| **ბგერის სიმბოლიკა** ბოროტისთვის | Khorne, Khârn, Tzeentch | ქართული თანხმოვანთკომპლექსები: **ღრ-, ხრ-, ყრ-, ღრჭ-** ბნელ სახელებში (არა **მღვ-** — „მღვდელს“ ემსგავსება); ნათელში — ღია ხმოვნები |
| **„ფერი/მასალა + არსებითი“** | Iron Hands, Black Templars | **რკინის-, ბრინჯაოს-, თუჯის-, ვერცხლის-, ჯაჭვის-, სისხლის-** + ჯარის სახელი |
| **ფრაქციის საკუთარი წოდებების კიბე** | Captain, Chaplain, Librarian | ყოველ ფრაქციას — თავისი წოდებები (იხ. ქვემოთ) |

## არ ვიყენებთ

- Warhammer-ის სიტყვებს და კომბინაციებს: Astartes, Primarch, Warmaster, Chapter, Inquisitor, Chaos, Warp, Heresy-ის GW-ის გაგებით და სხვ.
- Trench Crusade-ის სახელებს (იხ. `fact-check.md`).
- რეალური ღმერთების, წმინდანებისა და ცოცხალი რელიგიების სახელებს; რეალური დიქტატორების და ლიდერების მსგავსებას.
