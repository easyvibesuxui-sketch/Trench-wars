# იუნიტები

> სამუშაო ვერსია. აქ აღწერილია **როლები, აღჭურვილობა და ძალები** — ციფრების გარეშე.
> ზუსტი მახასიათებლები (მოძრაობა, სროლა, ხელჩართული, ჯავშანი), ფასები და ლიმიტები მექანიკის ეტაპზე დაემატება.

## დონეები
| დონე | რა არის |
|---|---|
| **I. ქვეითი** | იაფი, მრავალრიცხოვანი სანგრის ჯარი |
| **II. ელიტა** | ლიდერები, სპეციალისტები, რაინდები |
| **III. ჯავშნიანი** | მძიმე ჯავშანი, ორთქლის ჯავშანი, პროთეზები |
| **IV. გროტესკული** | ურჩხულები და გროტესკული ტანკები (რაზმში მაქს. 1) |
| **IV+. დიდი გროტესკული** | უზარმაზარი მავალი სიმაგრეები და ურჩხულები — IV დონის ადგილს იკავებს (მაქს. 1 IV-ის ჯამში) |
| **V. გოლიათი** | **სუპერიუნიტი** — მხოლოდ სპეციალურ სცენარებში / კამპანიის ფინალში |
| **გმირი** | **სუპერიუნიტი** — სახელდებული პერსონაჟი, რაზმში მაქს. 1, მხოლოდ სცენარით ან კამპანიაში |

## საერთო მექანიკის იდეები (ყველა ფრაქციისთვის)
- **ორთქლის წნევა** — ორთქლის იარაღი, ჯავშანი და პროთეზები წნევას აგროვებს. მეტი წნევა = მეტი ძალა. გადატვირთვა = აფეთქების რისკი.
- **გაზის ღრუბელი** — მოძრაობს ქარით, ორივე მხარეს აზიანებს. აირწინაღი იცავს, მაგრამ შეიძლება გაფუჭდეს.
- **ტყვეები** — დაჭრილი მოწინააღმდეგე შეიძლება ტყვედ აიყვანო: გამოსასყიდად, დასაკითხად ან (ბნელი მხარე) სამსხვერპლოსთვის.
- **ალქიმია** — მკვდარი წყალი (მკურნალობა), ცოცხალი წყალი (აღდგენა, ძალიან იშვიათი), დრაკონის კბილები (დათესილი მეომრები).
- **გოლიათზე ნადირობა** — ყოველ ფრაქციას ჰყავს სპეციალისტი, რომელიც გოლიათებსა და ურჩხულებს განსაკუთრებულ ზიანს აყენებს.
- **თხრილები** — მესანგრეებს ბრძოლის დროს თხრილის თხრა შეუძლიათ.
