# სანგრის რიგი — ბარათის თამაში ბრაუზერში

ერთი მოთამაშის ავტომატური ბრძოლის გარბენი „ქვესკნელის ფრონტის“ ბარათებით. გახსენი `index.html`. ქართულად და ინგლისურად.
წესები: `rules/trench-line.md` (თამაშში — ღილაკი „წესები“).

**როგორ თამაშდება:**
- აირჩიე ჯარი (31 ფრაქცია; დასაწყისში ოთხი ღიაა, დანარჩენს დონეები ხსნის).
- რუკაზე სამი ფრონტია, თითოში ექვსი კვანძი: ბრძოლა, რჩეული რაზმი, ბანაკი, საწყობი, ხდომილება და ბოლოს მთავარი ბრძოლა.
- ბრძოლის წინ **მობილიზაციაა**: მარაგით იყვან ბარათებს და რიგში ალაგებ. სამი ერთნაირი ერთ ★★ იუნიტად ერთიანდება.
- **ბრძოლა თავისით მიდის** და შემთხვევითობა არ აქვს. წინა იუნიტი წინას ებრძვის; „შორი“ მე-2 და მე-3 ადგილიდან ეხმარება;
  მკურნალი წინ მდგომს კურნავს. ყველა ბარათს თავისი უნარი აქვს (20 უნარი).
- მტრის რიგი და რელიეფი ბრძოლამდე ჩანს, ამიტომ მომზადება თავსატეხია: ვინ სად დადგეს და რომელი ბრძანება გამოიყენო.
- წაგება ნებისყოფას გაკლებს. რელიქვიები (18) მთელ გარბენს ცვლის.

**წინსვლა:** დონეები და ახალი ფრაქციები, სიმძიმის 9 საფეხური, დღის მისიები, მიღწევები, დღის გამოწვევა, ბარათების კრებული.
ყველაფერი ბრაუზერში ინახება (`tl-meta`, `tl-run`); გარბენი ავტომატურად ინახება.

**მართვა:** დააჭირე ბარათს — ქვემოთ გამოჩნდება, რას აკეთებს, და ღილაკები (აყვანა, დაკავება, დათხოვნა). შენი ბარათის გადასაადგილებლად
დააჭირე ჯერ მას, შემდეგ სხვა ბარათს ან ცარიელ ადგილს; კომპიუტერზე გადათრევაც მუშაობს. ბრძოლაში: სიჩქარე 1×/2×/4× და „გამოტოვება“.

**ფაილები:**
- `index.html` — ინტერფეისი; `engine.js` — წესები და ბრძოლის სიმულაცია (ბრაუზერში `window.TL`, node-ში `require("./engine.js")(CG)`);
- `data.js` — ბარათები (`window.CG`), აწყობს `tools/build_cardgame.py`; `balance.js` — ფრაქციების სირთულე (`tools/test_run.js … save`);
- ილუსტრაციები — ვიკის სპრაიტ-ფურცლები (`ln -s ../wiki/sheets cardgame/sheets`) და Kling-ის გრაფიკა (`ln -s ../assets/ui cardgame/ui`).

**ტესტები:**
```
node tools/test_run.js                 # წესების ტესტი + ბოტი გარბენებს თამაშობს (ბალანსი კვანძებით)
node tools/test_run.js 40 0 all save   # ყველა ფრაქციის მოგების % → data/run_winrates.json, cardgame/balance.js
NODE_PATH=$(npm root -g) node tools/test_run_ui.js   # ბოტი სრულ გარბენს თამაშობს ბრაუზერში, ტელეფონის სიგანეზე
```

# სამი ხაზი — ძველი ბრაუზერის ვერსია (`classic.html`)

ორი მოთამაშის ბარათის თამაშის (`rules/cardgame.md`, დასაბეჭდი ვერსია) ბრაუზერის ვარიანტი: კომპიუტერის წინააღმდეგ ან ორი მოთამაშე ერთ ეკრანზე. მთავარი თამაში ახლა „სანგრის რიგია“; ეს ვერსია `classic.html`-ში რჩება.

- **წესები:** `rules/cardgame.md` (თამაშის შიგნით — ღილაკი „წესები“).
- **დასტები:** 31 ფრაქციის სასტარტო დასტა (30–30 ბარათი), ფრჩხილებში მოგების წილი სიმულაციაში.
- **მონაცემები:** `data.js` (`window.CG`) აწყობს `tools/build_cardgame.py`: ბარათები, დასტები, ნიშნები, ინგლისური ტექსტები.
- **ილუსტრაციები:** ვიკის სპრაიტ-ფურცლები. აპი მათ `sheets/<ფრაქცია>.jpg`-ით ელის (`wiki/sheets/`, აწყობს `tools/build_wiki.py`).
  ადგილობრივად სანახავად `cardgame/sheets` უნდა მიუთითებდეს `../wiki/sheets`-ზე (მაგ. `ln -s ../wiki/sheets cardgame/sheets`).

**რეჟიმები:**
- **ერთი ბრძოლა:** შენი დასტა (31 სასტარტო ან შენი აწყობილი) კომპიუტერის ან მეორე მოთამაშის წინააღმდეგ.
- **დასტის ამწყობი:** ფრაქცია → ბარათები (ფრაქციის, იმავე მხრის მოკავშირეების — მაქს. 9, ერთი გმირი, საერთო); ყველა წესი მოწმდება;
  დასტები ბრაუზერში ინახება (`localStorage`, `cg-decks`).
- **კამპანია:** 6 ბრძოლა მოწინააღმდეგე მხარის წინააღმდეგ; ჯილდოდ სამი ბარათიდან ერთი (ზოგჯერ გმირი); 3 სიცოცხლე; ფინალში მტრის შტაბს 25 ნებისყოფა აქვს
  (`cg-camp`).
- **ხმა და ანიმაცია:** WebAudio-თი სინთეზირებული ხმები (ღილაკი „ხმა“), შეტევის და ჩამოსვლის ანიმაცია; „მოძრაობის შემცირებისას“ ანიმაცია გამორთულია.

**ინტერფეისის გრაფიკა (Kling):** `assets/ui/` — სამი მოედანი (`board_mud`, `board_snow`, `board_coast`; ბრძოლაში შემთხვევით, კამპანიის ფინალი — მთაში),
კამპანიის რუკა (`map_campaign`, ბრძოლების ნიშნულებით), მსოფლიო რუკა (`map_world`, ვიკის მთავარ გვერდზე), რკინის პანელი (`iron`), ქაღალდი (`paper`),
მენიუს ფონი (`title`), გამარჯვება/დამარცხება (`victory`, `defeat`). აპი მათ `ui/<სახელი>.jpg`-ით ელის; ადგილობრივად — `ln -s ../assets/ui cardgame/ui`.

**მართვა:** ბარათი ხელიდან → ოქროსფერი ადგილი ველზე. შენი იუნიტი → ოქროსფერი ადგილი (გადაადგილება) ან წითლად მონიშნული მტერი/შტაბი (შეტევა).
ნებისმიერ ბარათზე ან იუნიტზე დაჭერა მის აღწერას აჩვენებს. Esc — არჩევანის მოხსნა.

**კომპიუტერი** ორი სიძლიერისაა (არჩევა — ახალი თამაშის ეკრანზე):
- **ძლიერი** (`strongAction`): ყოველ ნაბიჯზე ყველა დასაშვებ მოქმედებას (ბარათი ყველა ადგილზე, შეტევა ყველა სამიზნეზე, გადაადგილება) თამაშის
  ასლზე ცდის და მიღებულ მდგომარეობას აფასებს (`evaluate`: შტაბები, ველზე მდგარი ძალა, ნეიტრალური ზოლები, შტაბზე საფრთხე, დაუცველი იუნიტები,
  ხელი, მზიდავები, ნაგებობები). საუკეთესოს ასრულებს, სანამ რომელიმე მოქმედება მდგომარეობას აუმჯობესებს. წონები (`DEFW`) შერჩეულია თვითთამაშით.
- **მარტივი** (`aiAction`): ისევე თამაშობს, როგორც ბალანსერის სიმულაცია (`tools/sim_cardgame.py`) — ძვირი ბარათები ჯერ, ჯერ შეტევა, მერე წინსვლა.

**წესების ინტერპრეტაცია** (`rules/cardgame.md`-ში ჩაწერილი): ახლა ჩამოსული იუნიტი ადგილზე რჩება; მეორე მოთამაშე +1 ბარათს და
პირველ სვლაზე +2 მარაგს იღებს; მესერს, ტყვიამფრქვევის ბუდეს და საგუშაგო კოშკს შეუტევ. მავთული, შენიღბვა და ზალპი თამაშში სრულად მუშაობს,
სიმულაციაში კი — ჯერ არა.

**უხილავი რეჟიმი:** `__cg.headless()` (`classic.html`) — ხატვის, ხმის და ანიმაციის გარეშე (ტესტები და ტიუნერი, ~11 ms თამაშზე).

**ტესტი:** `NODE_PATH=$(npm root -g) node tools/test_cardgame.js` — კომპიუტერი კომპიუტერს ეთამაშება 300-ჯერ; ამოწმებს, რომ შეცდომა არ არის, ყველა თამაში მთავრდება, პირველი სვლის უპირატესობა 35–65%-ის ფარგლებშია და ძლიერი კომპიუტერი მარტივს 60%-ზე მეტს უგებს.
