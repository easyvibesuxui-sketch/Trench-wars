# რაზმის ამწყობი (warband builder)

სტატიკური ვებგვერდი — გახსენი `index.html` ბრაუზერში (სერვერი არ სჭირდება).

- იუნიტები: `../data/units.json`; ფასები: `../data/costs.json` (ბალანსერი წერს).
- `data.js` და `ui-lang.js` გენერირდება ავტომატურად — ხელით ნუ შეცვლი.

## ქარ / EN
ზედა მარჯვენა კუთხეში ენის გადამრთველია (არჩევანი ბრაუზერში ინახება და ციფრულ თამაშებსაც ეხება).
- სახელები: `../data/names_en.json`; წესები, აღწერები, სცენარები, ნეიტრალური ზოლი, აღჭურვილობა, კამპანიები: `../data/text_en/` (`tools/i18n_en.py`);
- ინტერფეისის ფრაზები: `../data/ui_en.json` → `ui-lang.js` (წყარო: `tools/ui_lang.js`) — EN რეჟიმში გვერდის ტექსტს, canvas-ის წარწერებს და დიალოგებს თარგმნის;
- ახალი ქართული ფრაზა ინტერფეისში → დაამატე `ui_en.json`-ში, თორემ EN რეჟიმში ქართულად დარჩება;
- ტესტი ინგლისურ რეჟიმში: `TW_LANG=en node tools/test_builder.js` (იგივე შემოწმებები + გვერდზე ქართული ტექსტი აღარ უნდა დარჩეს; თამაშებისთვის — `test_digital.js`, `test_defense.js`).

## განახლება
```bash
python3 tools/validate.py        # მონაცემების შემოწმება (ყველა ფრაქცია)
python3 tools/balancer.py --sims 160 --calibrate 8 --support-sims 400 --warm   # ფასები: ერთი იუნიტის რაზმები, მხარდაჭერის ტესტი, ფრაქციების ბალანსი (~45 წთ)
python3 tools/build_campaigns.py # ომის კამპანიების დოკუმენტები (campaigns/*.md, lore/11-sacrifices.md)
python3 tools/build_builder.py   # builder/data.js-ის განახლება
NODE_PATH=$(npm root -g) node tools/test_builder.js   # ყველა ფრაქციის ავტომატური ტესტი ბრაუზერში
```

## წესები, რომლებსაც ბილდერი ამოწმებს
- ბიუჯეტი (500 / 750 / 1000 მარჩილი), აღჭურვილობის ჩათვლით;
- აღჭურვილობა და ალქიმია (`../data/equipment.json`): ფრაქციის შეზღუდვები, რაოდენობის ლიმიტი და მოთხოვნები (მაგ. დრაკონის კბილებს მედეას დები სჭირდება);
- ზუსტად 1 ლიდერი;
- რაოდენობის ლიმიტი: 500 მარჩილზე ერთ იუნიტზე მაქს. 10 (I დონე) ან 6 მოდელი (ბიუჯეტთან ერთად იზრდება);
- IV დონე (IV ან IV+) — მაქს. 1; IV+ — მხოლოდ 750+ მარჩილის თამაშში;
- გოლიათი (V) და გმირი — მხოლოდ სცენარის რეჟიმში, თითო მაქს. 1;
- მოკავშირეების დაქირავება (კოლხეთი, იბერია) — 24 მოკავშირე (თითოეულით ცალკეც შეიძლება თამაში): ევროპელები, რგოლის მეზობლები (სომხეთის მთიანეთი, ოღუზთა მიწები), ნილოსის მიწები, ყვითელი მდინარის მიწები, იაპონიის კუნძულები, კორეა, მონღოლეთი, ბალკანეთი, პირენეის ნახევარკუნძული, ალპები, ბალტიისპირეთი, პრუსია, ბატავები, ლეხია, ბიზანტია და ოსმალები. ყველა ფრაქციას ჰყავს რიგითები (აირწინაღით) და სანგრის მოჩხუბრები. ბიუჯეტის მაქს. 20%, ფასი +20%, პოლიანიცა — მაქს. 1.

## კამპანია
„კამპანიის“ ჩანართში რაზმი კამპანიად იქცევა: მეომრების გამოცდილება, ჭრილობები, ტყვეები, ხაზინა, ვალუტა (სახელი / წოდება / სისხლი) და ბრძოლების ჟურნალი. ყოველ ფრაქციას თავისი **ომის კამპანია** აქვს (`../data/campaigns/`): ჩანართი აჩვენებს შესავალს, მსხვერპლის ამბავს და 5 სცენარს — შემდეგი სცენარი ავტომატურად ირჩევა, მოგებული აღინიშნება, ბოლოს ჩანს დასასრული. წესები: `../rules/campaign.md`. კოდი: `campaign.js`.

რაზმი და კამპანია ინახება მხოლოდ ამ ბრაუზერში; სხვისთვის გასაზიარებლად ან სხვა მოწყობილობაზე გადასატანად გამოიყენე „ტექსტად კოპირება“ / „ექსპორტი“.
