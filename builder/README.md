# რაზმის ამწყობი (warband builder)

სტატიკური ვებგვერდი — გახსენი `index.html` ბრაუზერში (სერვერი არ სჭირდება).

- იუნიტები: `../data/units.json`; ფასები: `../data/costs.json` (ბალანსერი წერს).
- `data.js` გენერირდება ავტომატურად — ხელით ნუ შეცვლი.

## განახლება
```bash
python3 tools/validate.py        # მონაცემების შემოწმება (ყველა ფრაქცია)
python3 tools/balancer.py        # ფასების გადათვლა (~15 წუთი, ყველა CPU ბირთვზე)
python3 tools/build_builder.py   # builder/data.js-ის განახლება
```

## წესები, რომლებსაც ბილდერი ამოწმებს
- ბიუჯეტი (500 / 750 / 1000 მარჩილი), აღჭურვილობის ჩათვლით;
- აღჭურვილობა და ალქიმია (`../data/equipment.json`): ფრაქციის შეზღუდვები, რაოდენობის ლიმიტი და მოთხოვნები (მაგ. დრაკონის კბილებს მედეას დები სჭირდება);
- ზუსტად 1 ლიდერი;
- IV დონე (IV ან IV+) — მაქს. 1; IV+ — მხოლოდ 750+ მარჩილის თამაშში;
- გოლიათი (V) და გმირი — მხოლოდ სცენარის რეჟიმში, თითო მაქს. 1;
- მოკავშირეების დაქირავება (კოლხეთი, იბერია) — 24 მოკავშირე: ევროპელები, რგოლის მეზობლები (სომხეთის მთიანეთი, ოღუზთა მიწები), ნილოსის მიწები, ყვითელი მდინარის მიწები, იაპონიის კუნძულები, ინდოეთის ნახევარკუნძული, დასავლეთ აფრიკის მიწები, ჩრდილოეთ ამერიკის ტყეები, მექსიკის ველის ხალხი, ამაზონის ტყეები და მდინარეები, ანდების მთიანეთი, კარიბის კუნძულები, ოკეანეთის კუნძულები და აფრიკის სამი რეგიონი (ცენტრალური, სამხრეთი, დიდი ტბები). ბიუჯეტის მაქს. 20%, ფასი +20%, პოლიანიცა — მაქს. 1.
