# ქვესკნელის ფრონტი — სათამაშო ნაკრები („პირველი ღამე“)

პირველი სატესტო თამაშისთვის საჭირო ყველაფერი, ასაბეჭდად (A4, მასშტაბი 100%):

| ფაილი | რა არის |
|---|---|
| `kit.pdf` | **ნაკრები (11 გვ.):** ყდა · მოკლე წესები (2 გვ.) · სცენარი „ღამე დამწვარ სოფელში“ · ორი მზა რაზმი (300 მარჩილი) · 18 იუნიტის ბარათი · ნეიტრალური ზოლის ცხრილები (2 გვ.) · ჟეტონები და 3″ შაბლონი · სატესტო ფურცელი |
| `cards-all.pdf` | ყველა ფრაქციის (49) ყველა იუნიტის ბარათი — 63×88 მმ, 9 გვერდზე |
| `scenarios.pdf` | **სცენარების ნაკრები (7 გვ.):** გარღვევა · ღამის რეიდი · სიმაგრის დაცვა · ესკორტი · ურჩხულზე ნადირობა · ორი ალიანსი — რუკებით (წყარო: `data/scenarios.json`, ტექსტი: `rules/scenarios.md`) |
| `kit.html`, `cards-all.html`, `scenarios.html` | იგივე, ბრაუზერში სანახავად |

**რაზმები:** კოლხეთი — „ღარის საგუშაგო“ (10 მოდელი) და დიდი უღელი — „ღამის რეიდი“ (14 მოდელი). ბალანსერის სიმულაციით
(3000 ბრძოლა) კოლხეთი ~46%-ს იგებს — დაახლოებით თანაბარი.

**ბარათები:** ჩარჩოში ჩასმული ნიშნები და ქვემოთ დაწერილი ძალები — ზუსტი წესებია (`rules/abilities.md`; ნიშნების ლექსიკონი —
`cards-all.pdf`-ის ბოლოს). ძალების ფასი `ability_points`-ით შედის, ამიტომ სატესტო თამაში მათ ფასსაც ამოწმებს.

**ხელახლა აწყობა** (მონაცემების ან ფასების შეცვლის შემდეგ):
```
python3 tools/build_playtest.py
python3 tools/build_scenarios.py
NODE_PATH=$(npm root -g) node tools/print_playtest.js
```
რაზმები — `tools/build_playtest.py`, `WARBANDS` (ბიუჯეტზე მეტი რაზმი აწყობას აჩერებს).
