# ამბრის ღარი: ღარის დაცვა — ონლაინ tower defense პროტოტიპი

სამაგიდო რეჟიმის (`rules/defense.md`) ბრაუზერის ვერსია. გახსენი `index.html`. მონაცემები მოდის `data.js`-დან, რომელსაც
`tools/build_builder.py` აწყობს.

**რა არის:**
- აირჩიე შენი ფრაქცია (ნათელი მხარე, მოკავშირეების ჩათვლით), მტერი (4 ბნელი ფრაქცია) და რუკა (2).
- 28 × 16 უჯრიანი დაფა: ნაპრალი მარჯვნივ, ამბრის ბეჭედი მარცხნივ.
- **ლაბირინთი:** მესერი, მავთული და თხრილი **იწელება**. იუნიტი და კოშკი უჯრას იკავებს, მტერი კი უმოკლეს გზით მიდის; ეს გზა დაფაზე ჩანს. გზის ბოლომდე ჩაკეტვა არ შეიძლება.
- **ჩიხი:** ხელჩართულ ბრძოლას მიჩვეული ქვეითი მიმდებარე უჯრაზე მდგარ მტერს აჩერებს.
- **მსროლელები** ურტყამენ იმ მტერს, ვინც ბეჭედთან ყველაზე ახლოსაა.
- ტყვიამფრქვევი მტერს **ათრგუნავს**. თხრილში მდგომს **საფარი** აქვს.
- განსაკუთრებული მტრები:
  - **ფრენადი** ლაბირინთს ზემოდან უვლის;
  - **მესანგრე** მესერს ქვემოდან უვლის;
  - **გოლიათი** მესერს ამტვრევს.
- 20 ტალღა, ყოველ მეხუთეზე ბოსი, ბოლოს გოლიათი.
- **მარჩილი:** მოკლულ მტერზე, მოგერიებულ ტალღაზე, დანაზოგის სარგებელი და ტალღის ადრე გამოძახების ბონუსი.
- გაყიდვა 70%-ად; სიჩქარე ×1/×2/×3; შენი რეკორდი ინახება ამ ბრაუზერში.

**მართვა:**
- იუნიტი ან კოშკი: აირჩიე და დააწექი უჯრას.
- ხაზი: დააჭირე და გაწელე.
- დამცველზე დაჭერა: მოინიშნება და მისი რადიუსი გამოჩნდება.
- ჰარი (Space): ტალღა ახლავე.
- Esc ან მარჯვენა ღილაკი: გაუქმება.

**ტესტი:**
```
NODE_PATH=$(npm root -g) node tools/test_defense.js
TD_LAST=20 TD_SPEED=10 NODE_PATH=$(npm root -g) node tools/test_defense.js   # სრული თამაში ავტომატური მოთამაშით
```
ავტომატური მოთამაშე ბოლომდე ვერ აღწევს და დაახლოებით მე-15 ტალღაზე აგებს, თუმცა მარჩილი უხარჯავი რჩება. ეს ნიშნავს, რომ ჭკვიანური ლაბირინთით მოგება შესაძლებელია.
